隐私政策

运营者：个人。联系邮箱：husl@133.cn。版本：1.0.0。更新日期及生效日期：2026年10月12日。

本政策适用于头痛日记 iOS App、微信小程序，以及隐私政策、用户协议和支持网页。文中的“我们”指运营者，“你”指使用者。请重点阅读健康信息、本地保存与删除、PDF 外部副本的说明。

一、我们如何处理你的信息。 头痛、用药和你填写的“经期”等内容可能涉及敏感的医疗健康信息。客户端仅为你自己的记录、回顾、月度统计和所选月 PDF，在本端处理这些信息；运营者不能通过产品远程读取你的日记，不收集日记用于广告、营销、研究或模型训练。填写可能诱因或用药效果只表示你的记录，不构成诊断或疗效结论。

二、主动填写的记录。 记录包括头痛开始与结束时间、结束状态、疼痛程度、部位、可能诱因及自定义情境、用药情况、关联用药时间、药名、用量原文、主观效果和备注。开始时间与疼痛程度用于建立基础记录，其他信息按页面提示由你选择补充；未填写的内容不会由产品推断补齐。请避免在备注中写入身份证号、联系方式或与记录无关的他人信息。

三、本地运行信息。 客户端保存记录编号、本地保存版本及校验信息，以关联头痛和用药、核对保存结果；另保存你同意的政策版本，用于记住同意状态。微信端读取窗口尺寸、像素比例、安全区、系统字号和运行环境等平台返回信息，用于页面布局与本地运行，不用于识别或跟踪你，不上传给运营者。

四、保存位置与期限。 iOS App 与微信小程序分别在各自的本地容器保存，数据不互通，没有产品账户、手机号或微信身份绑定、业务云同步或业务服务器。日记在本端保留供你回顾，直至你修改、删除或本地数据被清理；没有按固定天数自动删除日记的规则。同意版本不随单条日记删除而清空。为避免保存中断丢失记录，客户端交替保存当前和上一版本的本地文件；上一版本可能含修改或删除前的内容，通常在下一次成功保存时覆盖。这是内部可靠保存机制，不是可供恢复的备份，也不表示删除后立即完成物理安全擦除。

五、保护措施及限制。 iOS 的日记和内部报告文件设置系统文件保护及排除系统备份属性。微信端使用小程序本地存储与文件容器。客户端校验保存结果，保存失败保留旧记录与当前输入；提交结果待确认时提示重新读取。请保护设备锁屏密码并谨慎允许他人使用设备。本产品没有独立密码锁；本地文件保护不代表数据绝不会损坏、泄露或被系统产生副本。首版不提供完整备份与恢复，卸载、清理应用或微信数据、换设备、本地文件损坏可能导致记录无法恢复。

六、权限、第三方代码与平台。 现有记录功能不请求通讯录、位置、相机、麦克风、照片、苹果健康或微信身份等权限，不自动读取健康或经期数据；“经期”由你手动选择。未接入广告、用户行为分析、跟踪或第三方云端统计 SDK。微信 PDF 使用随程序打包的 pdf-lib 在本地生成，库本身不向其提供方传输日记。Apple、微信、操作系统和你选择的文件服务可能按各自规则处理平台运行信息；本政策描述产品自身行为，不能代表这些平台不处理任何信息。

七、PDF 导出与外部副本。 你主动操作时，客户端在本端预览并生成所选月份的 PDF，不将日记上传服务器生成报告。报告可能包含该月涉及记录的头痛、用药和完整备注，请在保存或向他人提供前核对内容与接收方。内部报告文件在关闭报告、取消或相关清理流程中清理；你已取用的外部文件由你和所选文件服务管理。自行选择云文件服务时，副本可能上传至该服务；产品不会自动发送给他人。修改或删除日记不会同步修改或删除外部 PDF，应在保存位置另行处理。PDF 是阅读材料，不能恢复日记。

八、查看、更正、删除与撤回。 你可以在本端查看、补充、更正或逐条删除记录，也可生成所选月 PDF。删除头痛会同时删除关联用药；单独删除用药只影响该事件及相应摘要。首版没有批量清空、账号注销或单独撤回按钮。若不愿继续本地处理，可停止使用和填写，按需删除记录；如需移除整个本地容器，可使用系统卸载或微信提供的数据清理方式，事先确认记录无法恢复并另行管理外部 PDF。再次阅读政策不会清空日记。若需要了解操作方法、提出个人信息请求或投诉，请联系 husl@133.cn；由于运营者没有远程日记副本，不能代你读取、更正或删除设备上的记录。依法享有的个人信息权利不因上述技术限制而被排除。

九、邮件支持。 仅在你主动发送邮件时，运营者会收到你的邮箱地址、邮件内容和你自行附带的信息，用于回复、排查问题或处理个人信息请求；不用于广告或营销。请优先提供操作步骤、提示文字和去除健康内容的截图，不要发送密码、平台凭据或完整病历。邮件在处理请求及依法履行义务所必要的范围和期限内保留；你可以通过同一邮箱提出更正、删除或停止联系请求。邮件服务商按其自身规则处理邮件，不等于客户端自动上传日记。

十、公开网页。 政策与支持网页托管在 GitHub Pages，仅用于展示公开文字，没有日记录入、上传表单、分析脚本或第三方广告。访问网页时，GitHub 可能为提供服务和安全保障处理 IP 地址等访问日志，具体见 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。此类网页访问不包含客户端本地日记。

十一、未成年人。 未成年人应在监护人指导下阅读本政策、理解健康信息与本地数据风险，并根据适用法律取得必要的监护人同意。本产品不通过账号收集年龄或监护人身份，不设儿童专属服务。监护人如对邮件中提供的未成年人信息有疑问，可使用上述邮箱联系；不要为联系而主动提供额外身份或健康资料。

十二、政策更新及再次查看。 本文的版本、更新日期和生效日期在开头列明。你可在首次协议页面，以及统计页“导出PDF月报”下方的“隐私政策”“用户协议”重新查看正文。需要重新同意的实质变化会通过新版客户端的协议页面提示并重新取得同意，不以仅修改同版本网页代替这一过程。网页更新不自动改变已安装客户端的行为；新增处理目的、信息类型或第三方服务须先更新说明并按要求取得同意。如有问题，请联系 husl@133.cn。
